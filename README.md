# BrokerLens — demo

A clickable prototype of BrokerLens, a broker reputation platform for carriers and shippers.

**Open the demo:** https://soweasy-labs.github.io/brokerlens-demo/#tour

- Press **Next** (or →) for the 3-minute guided walkthrough. ← goes back, Esc exits.
- Every public review requires proof of the load (rate confirmation, BOL, POD, or invoice).
- Every broker, review, and identifier is fictional. The AI is simulated. Nothing is published or sent.
- The page is a single self-contained file (`index.html`) with no outside dependencies. Data you enter stays in your own browser.

BrokerLens is a working name.
